# The Lost Labyrinth of Mars
go through mars in my bad game

| Key | Action |
| --- | --- |
| WASD or arrow keys | Move astronaut |
| E | Interact with an item or doorway |
| B | Open/close backpack |
| 1 or 2 in story mode | Investigate or search for supplies |
| 3 in story mode | Leave encounter |
| 1 in backpack | Use Oxygen Tank |
| 2 in backpack | Use Medkit |
| Escape in backpack | Close backpack |
| R on end screen | Restart game |

## Setup

Run these commands from the project directory:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python gametings.py
```

My game uses `mars_labyrinth_rooms.csv` in the same directory as `gametings.py`.

## Project files

- `gametings.py`: Main Pygame game
- `mars_labyrinth_rooms.csv`: Fictional room dataset
- `requirements.txt`: Python dependencies
- `.gitignore`: Exclusions for local environments, keys, temporary files, and private notebooks
